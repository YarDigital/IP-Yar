<h1 align="center">IP Yar - IP Checker</h1>

<p align="center">
  A fast, free IP checker for your browser. See your IPv4, IPv6, ISP and DNS servers in one click, and look up any IP address or domain.
</p>

## Features

- **What is my IP:** your IPv4 and IPv6 addresses, detected automatically.
- **ISP and network details:** provider, organization and ASN, with country flags.
- **Location data:** country, city, region, timezone, latitude, longitude and postal code (approximate).
- **DNS servers:** see which DNS servers your browser is using.
- **IP lookup and domain lookup:** check any IP address, or see a domain's IP, ISP and DNS records.
- **Light and dark themes**, English and Persian interface.
